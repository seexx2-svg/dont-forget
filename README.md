# 贴心提醒 · Reminder 小程序

一个简洁智能的个人提醒小程序，专注于「不打扰、不漏事」。

## ✨ 功能特色

### 🎯 核心功能
- **AI 智能识别**：说一句话或输入文字，自动解析成结构化提醒（支持语音 + 文字）
- **六大分类**：缴费、健康、证件车辆、纪念日、自定义
- **模糊日期**：每天 / 每周 / 每月 / 每季度 / 每年，无需指定具体日期
- **智能重复**：自动滚动到下一个周期，永不遗漏
- **农历支持**：生日、纪念日可设置农历提醒，自动换算公历

### 🔔 推送机制
- **订阅消息**：微信服务通知主动推送
- **定时触发器**：云函数每 5 分钟检查，到期自动提醒
- **智能攒配额**：用户操作时静默攒配额，支持"离线也能推送"
- **本地弹窗**：打开小程序时检查到期提醒，兜底保障

### 🛡️ 隐私保护
- **本地存储**：所有提醒数据存储在本地
- **隐私锁**：支持密码锁定敏感页面
- **云推送按需**：只有需要推送时才上传云端

### 📱 用户体验
- **首页日历**：今日高亮，有提醒的日期标红点
- **分类筛选**：按分类快速查看
- **统计概览**：今日 / 即将到期 / 逾期 / 已完成
- **搜索**：支持标题、子类型、备注搜索

### 技术栈
- **前端**：原生微信小程序（WXML / WXSS / JS）
- **后端**：微信云开发（云函数 + 云数据库）
- **AI 解析**：智谱 AI 大模型（自然语言 → 结构化数据）
- **语音识别**：百度 ASR API
- **订阅消息**：微信一次性订阅 + 定时触发器

## 🚀 部署指南

### 前置条件
- 微信开发者工具
- 微信小程序账号
- 云开发环境（个人版可用）

### 部署步骤

1. **克隆项目**
```bash
git clone <repo-url>
cd reminder-miniprogram
```

2. **用微信开发者工具打开**
- 导入项目目录
- AppID 填入自己的小程序 AppID

3. **开通云开发**
- 点击「云开发」按钮
- 创建云环境

4. **部署云函数**
- 右键 `cloudfunctions/parseReminder` → 上传并部署
- 右键 `cloudfunctions/sendReminder` → 上传并部署
- 右键 `cloudfunctions/sendReminder` → **上传触发器**

5. **配置订阅消息模板**
- 微信公众平台 → 功能 → 订阅消息
- 添加模板：类目「备忘录」→「日程提醒」
- 复制模板 ID，填入 `cloudfunctions/sendReminder/index.js`

6. **配置 AI API Key**
- 在 `cloudfunctions/parseReminder/config.js` 填入智谱 AI 和百度 ASR 的 API Key

7. **编译预览**
- 点击「编译」→「预览」→ 扫码体验
